# FastMail - Email Client Server Application

Серверная часть приложения, имитирующего базовые функции ящика электронной почты.

## Технологии

- **Backend:** Python 3.10, Django 4.2+, Django REST Framework
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Database:** SQLite (по умолчанию)
- **Аутентификация:** Session Authentication

## Функционал

1. **Аутентификация:**
   - Регистрация нового пользователя
   - Вход/выход из системы

2. **Управление письмами:**
   - Отправка письма (с созданием копии для получателя в системе)
   - Просмотр входящих/исходящих писем
   - Просмотр содержимого письма (с автоматической отметкой о прочтении)
   - Перемещение писем между папками (Входящие, Отправленные, Архив, Корзина)
   - Удаление писем (Soft Delete)

3. **Папки:**
   - Inbox (Входящие)
   - Sent (Отправленные)
   - Archive (Архив)
   - Trash (Корзина)
   - Drafts (Черновики)

## Быстрый старт

### 1. Активация виртуального окружения

```bash
cd "fastmail_project"
..\venv\Scripts\activate
```

### 2. Запуск сервера разработки

```bash
python manage.py runserver
```

### 3. Доступ к приложению

Откройте в браузере: **http://127.0.0.1:8000/**

## API Endpoints

### Аутентификация
- `POST /api/login/` - Вход в систему
- `POST /api/logout/` - Выход из системы
- `POST /api/register/` - Регистрация нового пользователя
- `GET /api/me/` - Информация о текущем пользователе

### Письма
- `GET /api/emails/?folder=Inbox` - Список писем из папки
- `POST /api/emails/` - Отправить письмо
- `GET /api/emails/{id}/` - Просмотр письма
- `PATCH /api/emails/{id}/move/` - Переместить письмо в другую папку
- `DELETE /api/emails/{id}/` - Удалить письмо

## Особенности реализации

1. **Отправка писем:** При отправке письма пользователю, зарегистрированному в системе, копия автоматически создаётся в его папке "Входящие".

2. **Soft Delete:** Удалённые письма помечаются флагом `is_deleted=True` и перемещаются в корзину.

3. **Автоматическая отметка о прочтении:** При просмотре письма оно автоматически отмечается как прочитанное.

4. **Системные папки:** Создаются автоматически при миграции базы данных.

## Примечания

- Для production рекомендуется использовать PostgreSQL и настроить переменные окружения через `.env` файл.
- В production следует использовать более безопасные методы аутентификации (JWT или Token).
